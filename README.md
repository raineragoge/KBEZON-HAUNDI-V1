# KBZÓN HAUNDI — Verde Bosque V7

Web estática de dos páginas, preparada para Cloudflare Pages.

- `index.html`: inicio con accesos persistentes **Ver carta** y **Reservar**.
- `carta.html`: carta independiente; en móvil, las fotos se despliegan debajo de los platos sin desplazamientos automáticos.
- `assets/`: fotografías integradas en archivos locales para reducir el peso.

## Cloudflare Pages
En **Workers & Pages** importa este repositorio y selecciona como rama de producción `kbzon-v7-cloudflare`.
Framework: **None**. Build command: **vacío**. Build output directory: **.** (raíz del repositorio).
No requiere npm, Vite ni servidor.

Esta es una propuesta no oficial. Verifica licencias de fotografías, nombres de platos y carta vigente antes de su publicación comercial.
